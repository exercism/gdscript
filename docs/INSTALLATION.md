# Installation

The [Godot Engine][godot-engine] is used to run GDScript code.
The Godot Engine runs on Windows, Linux, macOS, and Android.



## Installing Godot Engine

The Godot Engine can be downloaded directly from [the Godot Engine website][godot-engine].
The download contains a single executable, named with the Godot Engine version.
This file needs to renamed `godot` and placed in one of the `$PATH` directories.
After completing the installation, you can verify if the CLI was installed successfully by running this command in a terminal:

```bash
godot --version
```

This track uses Godot version 4.7.2.
